# 中德智能制造学院面向2025级的辅修专业接收计划

来源通知面向各学院2025级普通本科学生，列出中德智能制造学院四个辅修专业的接收计划：机械设计制造及其自动化、电子科学与技术、自动化、机器人工程，各计划接收5人。[来源通知，开头及专业接收计划表](https://sgim.sztu.edu.cn/info/1171/4362.htm)

“2025级”指学生年级，不是通知发布日期。页面发布日期未知；计划人数不等于实际录取人数，也不能证明当前仍可申请。留存摘录在申请程序部分截断，不能据此形成完整或现行办事指南；通知引用的学籍管理规定尚未另行核验。
