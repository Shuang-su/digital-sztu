# 路线

## v0.1：事件可提交、关系可回查

- Event + Time + Claim/Citation
- 人物、组织、地点、制度、主题 Node
- Event 单写关系、Markdown wikilink 与自动 backlink
- 自动生成各 Node 目录索引
- 编年体、纪传体、典制体和专题 Collection
- Codex plugin + 本地 CLI
- 供应商无关知识 JSONL

## 下一步

- 从公开、低争议来源建立首批真实 Event
- 增加 Event 重复检测和 Node 别名消歧
- 增加显式 Markdown chunk anchor
- 提供本地全文／向量检索参考实现
- 增加静态只读浏览器

MCP、WebMCP、云端向量库、网页归档和部署在有真实需求与可测试 runtime 后再决定。

## 长期路线

在不改变 Event 历史语义的前提下，项目将逐步覆盖校园历史、校园档案、校园信息和校园知识，并建设社区可治理、Agent 可协作、证据优先、时间感知且本地可重建的知识基础设施。

这是长期方向，不表示 Knowledge Record、全文或混合检索、RAG、网站和持续信息监测已经实现。完整的阶段拆分、信任边界与验收条件见 [长期路线 Issue #1](https://github.com/Shuang-su/digital-sztu/issues/1)。
